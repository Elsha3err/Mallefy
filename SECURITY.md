
# Security Policy

## Reporting a Vulnerability
Please do NOT open a public issue. Report vulnerabilities privately
to the maintainers (use GitHub's "Report a vulnerability" button
under the Security tab).

## Supported Versions
| Version | Supported |
| ------- | --------- |
| 1.1.x   | ✅        |
| < 1.1.0 | ❌        |

## Data Protection
PDF operations (merge, compress, convert, split, edit) run locally
on the user's device. Documents are not uploaded to any server.
Only anonymous usage telemetry is sent to the analytics server.
